# MVP Scope

Included: account and role access, one-institution-at-a-time isolation, categories and locations, lost/found reports, secure local images, deterministic search, claims, officer decisions, handovers, in-app notifications, audit, analytics, controlled extensions, Docker, migrations, seed data, and tests.

Deferred: semantic AI/vector/image matching, email/SMS/WhatsApp, SSO, multi-tenant administration, WebSockets, complex workflow builders, enterprise storage, distributed infrastructure, archival automation, and a plugin marketplace.
