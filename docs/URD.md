# User Requirements

Students need two obvious choices—“I Lost Something” and “I Found Something”—with category-first guidance, preserved browser form state, clear errors, meaningful empty states, references, and status tracking. Finders need only relevant item, place, date, custody, and optional photo fields. Claimants must provide a private distinguishing detail.

Officers need a focused review queue, private evidence, explicit decisions, rejection reasons, and handover controls. Administrators need truthful institution-scoped metrics and audit records. Every journey states its step, uses plain language, supports keyboard navigation, and keeps ownership decisions human-controlled.
