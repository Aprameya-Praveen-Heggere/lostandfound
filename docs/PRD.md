# Product Requirements

The MVP enables institutional users to register/login, report lost or found items, upload a found-item photo, search strictly within a category, see explainable deterministic relevance, submit private ownership evidence, and track reports, notifications, and claims. Officers review, approve/reject with a mandatory reason, update custody, and record handovers. Administrators see real metrics and audit history.

The target is a responsive, accessible interface and standard database API responses below 500 ms p95 under a defined moderate load; this repository does not claim the performance target without environment-specific load testing. Reliability uses transactions, health/readiness checks, persistent volumes, logging, validation, and migrations.
